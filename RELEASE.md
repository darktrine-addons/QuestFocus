## v1.0.0 — 2026-11-23

QuestFocus leaves beta. It has been daily-driver stable for months; this release adds translations and marks it as a full release.

### New features

- feat: **Simplified and Traditional Chinese translations** — the settings panel, menus, tooltips, keybindings and chat messages are now fully translated for zhCN and zhTW clients. English clients are unchanged. Thanks to **Lograthmic** for the translations and the localization groundwork ([#3](https://github.com/darktrine-addons/QuestFocus/pull/3)).

### Improvements

- QuestFocus is now ready for translation into further languages — all player-facing text goes through a single translation table.
